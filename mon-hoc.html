Bản 0.3 — gói môn học nạp theo nhu cầu, kéo thả trực tiếp

Cùng một ngôn ngữ hình ảnh cho toán, vật lý, hóa và giải thuật.

Mỗi môn là một gói riêng trong src/subjects/, chỉ được tải khi trang có hình của môn đó. Lõi dùng chung: hệ phản ứng, hệ trục, sân khấu không trục, trình phát từng bước, bộ giải phương trình vi phân, điều khiển và các khối học tập.

Mẫu một bài học

Hình động chỉ là một bước. Một bài học đầy đủ đi theo thứ tự: lý thuyết ngắn → dự đoán → xem và thao tác → tự giải rồi mở lời giải từng bước → tự kiểm tra không nhìn lời giải.

Lý thuyết. Hàm ghép nhánh liên tục tại $x_0$ khi và chỉ khi $\lim_{x\to x_0^-} f(x) = \lim_{x\to x_0^+} f(x) = f(x_0)$. Trên mỗi khoảng còn lại hàm là sơ cấp nên tự động liên tục.

  1. Trên $(-\infty; 1)$ và $(1; +\infty)$, $f$ là hàm sơ cấp nên liên tục. Do đó chỉ cần xét tại $x = 1$.
  2. $f(1) = 2\cdot1^2 = 2$ và $\lim_{x\to1^+} f(x) = \lim_{x\to1^+} 2x^2 = 2$.
  3. $\lim_{x\to1^-} f(x) = \lim_{x\to1^-}(ax - 2) = a - 2$.
  4. $f$ liên tục tại $1 \iff a - 2 = 2 \iff a = 4$.
 Tìm $m$ để $f(x) = \dfrac{e^{-3x}-1}{\sin x}$ khi $x \ne 0$, $f(0) = m$ liên tục trên $\mathbb R$ (ĐT03). $f(x) = \dfrac{\sin x}{|x|}$ ($x \ne 0$), $f(0) = 1$. Điểm $x = 0$ là loại gián đoạn nào? (Dạng 4, bài 1a)

Hóa đại cương

Động học phản ứng: nhận ra bậc phản ứng từ hình dạng đồ thị và từ chu kỳ bán hủy.

Gói thuat-toan

Cấu trúc dữ liệu và giải thuật

Thuật toán là quá trình rời rạc, nên dùng trình phát từng bước thay cho animation liền mạch: tiến, lùi, tua, đồng bộ với mã giả.

Viết một gói mới

Một gói là một thư mục trong src/subjects/ với tệp index.js, khai báo trong src/tiemcan.js bằng registerPack. Gói chỉ import từ src/api.js, không chạm vào lõi.

// src/subjects/xac-suat/index.js
import { definePack, scope, figure, signal } from '../../api.js';
const scene = scope('xac-suat');

scene('bernoulli', {
  params: { p: 'number', n: 'int' },
  defaults: { p: 0.5, n: 200 },
  mount(host, p) {
    const F = figure(host, p);
    const b = F.board({ x: [0, p.n], y: [0, 1] });
    // … dựng hình bằng b.curve, b.dots, F.slider, F.readout, F.status …
    return { destroy: () => F.destroy() };
  },
});
definePack('xac-suat', { name: 'Xác suất thống kê', presets: { … } });

// src/tiemcan.js
registerPack('xac-suat', { name: 'Xác suất thống kê', load: () => import('./subjects/xac-suat/index.js') });
